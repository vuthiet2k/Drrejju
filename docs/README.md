# DR.REJU — Docs

Tài liệu chuẩn cho theme Sapo/Bizweb của DR.REJU. **Độc lập, không liên quan Pharma Cosmetics** — chỉ chứa rule/convention chung của Liquid/Sapo.

| File | Nội dung |
|---|---|
| [`sapo-objects.md`](sapo-objects.md) | Object schema Liquid (store, product, collection, cart, customer, order, blog, page, linklist…) + các `type` settings hợp lệ + `img_url` sizes |
| [`sapo-conventions.md`](sapo-conventions.md) | Quy chuẩn viết theme: cấu trúc thư mục, cú pháp `.bwt`/Liquid, Sapo-vs-Shopify, đặt tên, CSS/SCSS, ảnh, settings 2-file, thang ưu tiên giải pháp, grunt-bizweb |
| [`review-checklist.md`](review-checklist.md) | Checklist tự review trước khi commit |
| [`design-brief.md`](design-brief.md) | Brief thiết kế & nội dung DR.REJU (đang chờ bạn chốt palette/font/section) |

Skill frontend: `.claude/skills/drreju-frontend-skill/` (stack Vue CDN + Tailwind + Font Awesome).

> Nguồn: rút & làm sạch từ convention chuẩn Sapo, bỏ toàn bộ nội dung/brand Pharma. Bổ sung thêm khi có tài liệu DR.REJU.
